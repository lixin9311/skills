# AI Skills Marketplace

A public repository for collecting, organizing, and sharing reusable AI skills.

## What this repository is for

This repository acts as a simple marketplace where each skill lives in its own folder and can be shared publicly.

## Marketplace structure

- `skills/` - published skills and the marketplace catalog
- `skills/_template/` - starter files for creating a new skill

## Add a new skill

1. Copy `skills/_template/` into a new folder under `skills/`
2. Rename the folder with a clear skill slug such as `skills/customer-support-agent`
3. Update the skill README and prompt content
4. Add the skill to the catalog in `skills/README.md`

## Publishing guidelines

Each skill should include:

- a clear name
- a short description
- intended use cases
- setup or usage instructions
- the prompt, workflow, or assets needed to run it

Start with the template in `skills/_template/`.
